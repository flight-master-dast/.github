# Flight Master DAST

**Flight Master DAST（航班管家 DAST）** provides professional aviation data and MCP services for developers, AI agents, and aviation-related applications.

Our aviation data capabilities are available through the **Model Context Protocol (MCP)**, enabling MCP-compatible AI agents and developer tools to access flight and airport data through a standardized remote interface.

## Flight Master Aviation Data MCP

**Remote MCP Endpoint**

```text
https://fly.huoli.com/mcp/dast_mcp
```

- **Protocol:** Model Context Protocol (MCP)
- **Transport:** Streamable HTTP
- **Authentication:** Bearer API Key

### Core Capabilities

- Flight status and flight dynamics
- Route and airport-pair flight queries
- Onboard experience and flight comfort information
- Flight delay and cancellation risk prediction
- Airport weather forecasts
- Real-time and historical flight trajectory data
